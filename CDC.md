# BUT.

- Generer un projet Flutter avec une architecture Flutter bien defini des templates de structure de projets predefinie.

- Le but est de creer un CLI qui agis comme ceci.

# INTERFACE
```bash
>>> geneser

<<< Nom du projects

<<< choisir des templates.
  exemple : CodeWithAndrea Template , MVVM simple.
  
<<< cocher les librairies tierces a utiliser a utiliser : Firebase , Supabase .

<<< Cocher les features a implementer
    exemple :  authentification , notifications push .

```



# ADMINISITRATION:

- En definit un template dans un fichier .yaml

```
version : 12
name : 15

folder structure:
  - repository.
    template:
      
  - service.
  - route
  - state
  - screen
  - shared



```


# TECHNOLOGIES D'implementation du projets.


- JAVA 
- Outils CLI.
- Configuration de template en fichiers .yaml
